# Formato de evaluación de proveedor

## Objetivo

Registrar la evaluación de un proveedor, contratista o subcontratista conforme a los criterios y umbrales definidos en APO-COM-EVP-PRO-001.

## Criterios de evaluación

| Criterio | Descripción | Puntaje (1-5) | Observaciones |
|---|---|---|---|
| Documentación legal (crítico) | RUC y permisos aplicables a su actividad, vigentes. | | |
| Referencias / experiencia | Referencias comerciales o experiencia previa verificable. | | |
| Capacidad técnica y financiera | Capacidad para el volumen y la complejidad requeridos. | | |
| Certificaciones de personal (crítico si aplica) | Solo para trabajos de riesgo: certificaciones vigentes conforme a APO-THU-GDR-MAT-001. | | |
| Código de Conducta | Aceptación expresa de EST-DIR-GOB-POL-001. | | |
