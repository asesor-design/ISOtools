# Matriz de riesgos y oportunidades

## Cómo leer esta matriz

Cada riesgo se califica con **Probabilidad × Impacto** (escala 1, 3, 5). El producto define el nivel: **ALTO** (15), **MEDIO** (5 a 9) y **BAJO** (3). La columna "Ejecutor" usa los cargos reales del organigrama vigente; la versión anterior usaba otros nombres de cargo, que se conservan en el archivo Excel original para trazabilidad.

Elaboró: Gestión y Control · Aprobó: Gerencia General.
